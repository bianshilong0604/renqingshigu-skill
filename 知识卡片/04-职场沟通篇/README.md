---

## 一、本篇核心命题

**职场不是 e 人的天下,升级后的 i 人思维极具竞争力。**

本篇的核心命题是:i 人无需把自己改造成八面玲珑的外向者,而是要用最低的能耗、最适合自己的方式,把天生的**深度思考力、敏锐观察力、共情能力**转化为职场竞争力。

贯穿全篇的一个底层逻辑是:**在职场,你的价值不会自动被看见,你需要学会"翻译"和"呈现"。** 沉默不是金,而是默认。从入职到离职,每一个关键节点,都是一次"精准呈现价值"的机会。

## 三、高复用话术框架速查表

| 框架 | 公式 | 适用场景 | 出处 |
|-----|------|---------|------|
| **黄金圈汇报** | Why(目的价值)→ How(方法过程)→ What(结果/需求) | 向领导汇报(方案请示/进度同步/问题求助/结果复盘) | 第29课 |
| **PRS 模型** | Problem(问题)→ Reason(原因)→ Solution(方案) | 即兴发言、分析问题、提建议 | 第30课 |
| **FFC 模型** | Feeling(感受)→ Fact(事实)→ Compare(对比) | 即兴评价、表达看法 | 第30课 |
| **时间轴模型** | 过去 → 现在 → 未来 | 总结、谈展望、分享心得 | 第30课 |
| **三级防御** | 防火墙(留痕)→ 拆弹(澄清+证据)→ 清算(单独汇报) | 被同事甩锅 | 第31课 |
| **接批评四步法** | 承接情绪 → 确认事实 → 担责+计划 → 感谢反馈 | 被领导批评 | 第32课 |
| **商业计划书五步** | 共同目标 → 现状差距 → 具体方案 → ROI回报 → Plan B | 争取人力/预算/权限 | 第33课 |
| **器重四支柱** | 极致靠谱 + 预期管理 + 心理可见性 + 战略曝光 | 获得领导器重 | 第34课 |
| **冲突降级四步** | 暂停 → 重构问题 → 聆听利益 → 共创方案 | 同事矛盾 | 第35课 |
| **"我"陈述句** | 陈述事实 + 表达感受(不指责) | 一切冲突场景 | 第35课 |
| **目的先行** | 先说"要干什么/需要你做什么",再展开 | 所有线上沟通 | 第36课 |
| **话题金字塔** | 塔尖(禁区)/ 塔身(中性)/ 塔基(观察兴趣点,最安全) | 办公室闲聊选题 | 第37课 |
| **闲聊三部曲** | 破冰 → 维持(倾听捧哏)→ 优雅撤退 | 茶水间/电梯/午休 | 第37课 |
| **跳槽三步曲** | 提离职(感谢→告知→表态)→ 交接 → 告别 | 离职全过程 | 第38课 |

### 跨课通用心法

- **靠谱铁律**:凡事有交代,件件有着落,事事有回音(贯穿27/34课)
- **核心觉悟**:沉默不是金,沉默是默认;价值不会自动被看见,要主动呈现
- **i 人优势牌**:认真、靠谱、谦逊、深度思考、善于倾听——这是底牌,不是短板
- **情绪管理通用动作**:深呼吸→按下暂停键→对事不对人(贯穿32/35课)

## 四、学习建议

### 1. 按"职场阶段"对号入座,不必通读

12 课覆盖职场全周期,但你不必一次学完。根据你**当前所处的阶段**优先学:
- **刚入职/转岗** → 先看 27、28
- **总觉得不被看见** → 先看 29、34
- **怕开会发言** → 先看 30
- **正受委屈(甩锅/批评/冲突)** → 看 31、32、35
- **想要资源/升职** → 看 33、34
- **每天被消息淹没** → 看 36
- **准备跳槽** → 看 38

### 2. 框架先记"骨架",再填"血肉"

每个框架先记住公式缩写(如 Why-How-What、PRS、商业计划书五步),形成肌肉记忆。真实场景来临时,大脑能快速调用"脚手架",而不是临场慌乱。

### 3. 用好每张卡的"个人笔记区"

所有方法论只有结合你的真实场景才有用。务必填写每张卡片的笔记区:写下你的汇报草稿、你的安全话题库、你的核心人脉清单。**把通用模板变成你的专属话术。**

### 4. 从"低成本练习"开始

- 即兴发言:先在心里用 PRS 总结新闻看法
- 线上沟通:本周先戒掉"在吗?",改用目的先行
- 办公室闲聊:本周主动发起一次不超过2分钟的塔基话题闲聊

### 5. 善用 i 人的"书面沟通"优势

本篇反复强调:复杂汇报、资源申请、冲突化解,都可以**先用书面(邮件/消息)打头阵**。文字给了 i 人思考和组织语言的时间,是把劣势转为优势的关键杠杆。
