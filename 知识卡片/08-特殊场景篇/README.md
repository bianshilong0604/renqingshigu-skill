### 4️⃣ 实战演练方法

**方法1: 镜子演练法**
- 对着镜子练习话术
- 观察自己的表情和肢体语言
- 录音回放,检查语速和语气

**方法2: 情景模拟法**
- 找信任的朋友模拟场景
- 尤其适用于:商务饭局、面试
- 请对方给反馈和建议

**方法3: 写作内化法**
- 把话术写在笔记本上
- 每个场景写3-5遍
- 通过书写加深记忆

**方法4: 真实应用法**
- 在真实场景中应用
- 每次应用后复盘:哪些有效?哪些需要改进?
- 持续迭代优化

### 5️⃣ 能量管理提示

特殊场景往往高能耗,**务必注意:**

✅ **事前充电**: 高压场景前一天,安排独处充电时间

✅ **事中微休息**: 利用洗手间、帮忙等理由,给自己5-10分钟喘息

✅ **事后脱敏**: 高压场景后,必须安排独处时间(1-3小时),清理"余震"

✅ **接受不完美**: 完成核心任务就是胜利,不必让所有人满意

✅ **能量预算**: 一周内不安排超过2个高压场景
