# 知识卡片 - 总览

> 结构化的社交技能知识库,每个卡片对应一个核心技能

## 📂 目录结构

```
知识卡片/
├── 01-基础准备篇/     # 认知升级、心态建设
├── 02-表达能力篇/     # 说话技巧、表达框架
├── 03-关系破冰篇/     # 识人、破冰、融入
├── 04-职场沟通篇/     # 向上管理、平级协作
├── 05-人情世故篇/     # 送礼、请客、托人办事
├── 06-自我保护篇/     # 拒绝、识人、防小人
├── 07-实战工具篇/     # 话术库、模型、技巧
└── 08-特殊场景篇/     # 春节、婚礼、商务
```

## 🎯 卡片设计理念

每张知识卡片包含:
- ✅ **核心原理**: 为什么这样做
- ✅ **实战步骤**: 怎么做(可操作)
- ✅ **话术示例**: 具体说什么
- ✅ **常见误区**: 避免踩坑
- ✅ **实践练习**: 如何练习

## 📋 使用方法

### 方式1: 按模块系统学习
从01-基础准备篇开始,依次学习各模块

### 方式2: 按需速查
遇到具体场景,直接查找对应卡片

### 方式3: 制作闪卡
将核心要点制作成闪卡(Anki/备忘录),碎片时间复习
