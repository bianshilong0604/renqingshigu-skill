# 个人社会化应对 Skill

这是一个面向真实社交场景的中文 Codex Skill。用户提供结构化背景后，它根据规则和实战案例生成自然、可直接使用、能够应对追问的回复。

## 包含内容

- `SKILL.md`：Skill 主入口与调用契约
- `references/可执行规则库_Rules_v1.2.1-social-flow.md`：G01–G13、R-L01–R-L78
- `references/规范化知识地图.md`：78 课规范化地图
- `references/实战案例路由索引.md`：199 个案例/示范单元
- `references/具体理由模板库.md`：低风险具体理由候选
- `知识卡片/`：89 个 Markdown 知识卡片
- `tests/`：三轮规则级回归测试报告

## 安装

将整个 `personal-social-coach` 文件夹复制到 Codex 的 skills 目录，例如：

```text
~/.codex/skills/personal-social-coach/
```

然后在新任务中使用 `$personal-social-coach`，或让 Codex 根据描述自动调用。

## 推荐输入

```text
场景与当前任务：
对方关系与权力差：
对方原话或可观察行为：
我的真实目标：
时间、精力与资源约束：
安全风险：
```

不需要每次填满；只有缺失信息会改变结论时才追问。

## 示例对话

### 示例一：请人引荐专业人士

**输入：**

```text
场景与当前任务：想请一位行业老师帮忙引荐专家
对方关系与权力差：认识但不算很熟，对方以前聊过这个领域
对方原话或可观察行为：暂无
我的真实目标：最终获得合适的专家联系方式
时间、精力与资源约束：不着急，希望第一条消息自然一些
安全风险：无
```

**推荐输出：**

> XX老师，最近还好吗？我这边最近在推进 XX，正好碰到一个 XX 方面的问题，自己研究了一阵还是有些拿不准。想到您之前好像聊过这一块，想先听听您的意见——像这种情况，一般找哪类老师或者业内人士请教会比较合适？

对方回复后再说：

> 明白了。那如果您觉得合适，之后方便的话能不能帮我搭个线认识一下？我先把背景和问题整理清楚，不会占对方太多时间。

### 示例二：商务饭局中被劝酒

**输入：**

```text
场景与当前任务：商务饭局中客户劝酒
对方关系与权力差：客户，关系需要维护
对方原话或可观察行为：来来来，这杯得喝一个
我的真实目标：表达尊重，但不接受拼酒
时间、精力与资源约束：可以少量饮酒
安全风险：无
```

**推荐输出：**

> X总，您这杯我肯定得接，今天能一起吃饭我也特别高兴。就是我今晚确实得收着点，酒我就不跟您硬拼了。这样，我认真敬您一杯，心意肯定不能少。

如果对方继续劝：

> 您这么说我更得敬您了，不过我要是真跟您拼酒，后面该聊的正事估计就聊不明白了。今天我先把这份心意敬到，改天咱们有机会我再好好陪您。

### 示例三：亲戚催婚式追问

**输入：**

```text
场景与当前任务：家庭聚会中被长辈问婚恋情况
对方关系与权力差：亲戚长辈
对方原话或可观察行为：有对象了吗？要不要我给你介绍？
我的真实目标：不伤关系，也不接受被安排
时间、精力与资源约束：希望委婉转开话题
安全风险：无
```

**推荐输出：**

> 谢谢您惦记，这方面我会按自己的节奏来，真有合适的我一定告诉您。对了，您最近身体怎么样？

如果对方继续：

> 谢谢您关心，我目前还不着急，还是想先按自己的节奏来。您先吃菜，咱们聊聊您最近的事。

### 示例四：明确工作任务不绕弯

**输入：**

```text
场景与当前任务：晚上收到领导的工作消息
对方关系与权力差：领导
对方原话或可观察行为：明早客户会议需要一份方案
我的真实目标：确认收到，明早处理
时间、精力与资源约束：今晚已有安排
安全风险：无
```

**推荐输出：**

> 收到，明早 9 点我上班后先处理这份方案。我晚上还有事，不太方便跟进；如果今晚有必须确认的截止点，您直接告诉我，我明早优先看。

这些示例展示的是表达顺序，不要求逐字照搬。实际回答会优先使用用户提供的真实关系、原话和约束。

## 数据边界

本 GitHub 版本只包含用于 Skill 运行的 Markdown 知识内容。原知识库中的 `实践记录/`、`.obsidian/` 和 `原材料/` 未纳入：前两者属于个人运行数据或本机配置，后者为非运行时 PDF 原材料。

如果仓库公开发布，请先确认这些用户自有知识卡片适合公开；默认建议使用私有仓库。
