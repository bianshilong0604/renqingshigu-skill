# Personal Social Coach：仓库内知识资源路由

本仓库是可移植版本。Skill 只能使用仓库内的相对路径，不依赖任何特定电脑的盘符、用户目录或外部知识库位置。

- `references/实战案例路由索引.md`
  - 199 个从知识卡片抽取的案例/示范单元。

## 检索顺序

1. 先用结构化输入识别安全风险、目标、关系/权力、请求成本、压力等级和时间阶段。
2. 再在规则基线中定位一个主规则，最多两个辅助规则。
3. 只有规则不足以决定话术形状时，才从案例索引定位一到两个相近案例。
4. 如果需要具体理由，再读取理由模板库，并让用户选择真实适用的候选。
5. 输出时只呈现必要的依据和话术，不把检索过程当成答案主体。
